== Description ==

Lightweight WordPress security plugin.

Features:
- Hide login links (lost password, register)
- Disable XML-RPC
- Restrict REST API (allow only Contact Form 7 endpoint)
- Protect wp-admin
- Brute force protection
- Hide WordPress version

== Installation ==

1. Upload plugin
2. Activate
